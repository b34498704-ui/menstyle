# MENSTYLE — интернет-магазин мужской одежды (React + Vite)

## Запуск
```bash
npm install
npm run dev            # сайт: http://localhost:5173
```
Оплата картой (отдельный сервер):
```bash
cd server && npm install
cp .env.example .env   # заполните ключи
npm start              # из папки server:  node index.js   (порт 4000)
```
В корне проекта при необходимости: `cp .env.example .env` (VITE_API_URL — адрес сервера оплаты).

## Доступ администратора
Email: `admin@menstyle.kg`, пароль: `admin123` — **смените в production**. Раздел «Админ» появляется в меню после входа.

## Оплата (Visa / Mastercard / Элкарт)
1. Выберите провайдера эквайринга в Кыргызстане с официальным API и страницей оплаты (hosted payment page), подпишите договор, получите ключи.
2. Вставьте в `server/.env`: `PAYMENT_API_URL`, `PAYMENT_API_KEY`, `PAYMENT_WEBHOOK_SECRET`, а `PUBLIC_SERVER_URL` — публичный https-адрес сервера (для webhook).
3. В `server/index.js` найдите комментарии `TODO` и приведите названия полей, заголовка подписи и статусов к документации вашего провайдера.
4. В кабинете провайдера укажите webhook: `https://ВАШ_СЕРВЕР/api/payments/webhook`.

Данные карт сайт не принимает и не хранит — пользователь переходит на страницу провайдера. Статус «Оплачено» ставится только после подписанного webhook. Если сервер/провайдер не настроен, заказ получает статус «Ошибка оплаты», а не «успех».

## Хранение данных
Сейчас товары, пользователи, заказы и корзина хранятся в `localStorage` браузера (работает без настройки, удобно для демо). Для настоящего магазина перенесите их в Supabase/Firebase: все операции собраны в `src/store.jsx`. Важно: проверка роли администратора и пароли в браузере НЕ защищены — в production нужны серверная авторизация и правила доступа (RLS).
